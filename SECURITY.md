# Security Policy

This project is not production software. Do not use it to store or transfer real value.

Do not post private keys, seed phrases, passwords, API keys, or wallet backups in issues.
When a working implementation exists, security reports should be sent privately to the
maintainers using a published security contact. No security contact is configured yet.

A public launch must not happen before independent security review, testnet operation,
and a documented vulnerability-response process.
